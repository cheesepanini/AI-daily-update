# 调试样例

本目录包含从运行数据选取的固定卡片样本，以及按卡片 ID 关联的反馈、特征。覆盖不同采集日期、主题、来源和审核状态；详细数量见 manifest.json。生成内容用于复现软件行为，不代表经过核实的事实。

不包含 PPT 讲稿、配置、备份、完整数据库或环境密钥。反馈操作人已统一为 demo-user，服务器项目路径已转为相对路径。样例不是完整历史，不用于评估生产统计或训练效果。

## 在独立目录运行

在仓库根目录安装依赖后执行：

```bash
python -m venv .venv
. .venv/bin/activate
pip install -e ".[dev]"
python scripts/create_demo_workspace.py ../ai-daily-demo
cd ../ai-daily-demo
ai-daily index
ai-daily serve --host 127.0.0.1 --port 8002
```

初始化脚本要求目标目录不存在，避免覆盖已有数据。演示环境关闭定时采集和自动审核，生成随机的本地登录密码并保存到目标目录 .env；用户名为 demo。请在该文件查看密码。浏览卡片无需配置 LLM，生成内容时需自行填写模型与 API 配置。

卡片采用快照中的历史日期，查看列表和简报时请选择对应日期范围（2026-07-06 至 2026-09-20 为采集日期范围，事件日期可能更早）。数据库由样例卡片在目标机器上重新建立，避免携带原服务器绝对路径。
