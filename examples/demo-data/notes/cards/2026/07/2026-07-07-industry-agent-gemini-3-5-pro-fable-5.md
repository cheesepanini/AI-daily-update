# 知识卡片：Gemini 3.5 Pro泄露，前端能力超越Fable 5

**一句话结论**  
传闻谷歌 Gemini 3.5 Pro 将于7月17日发布，其前端与视觉代码生成能力显著超越 Fable 5，但在硬核推理、仓库级工程和长程 Agent 任务上仍不及 Fable 5 与 GPT-5.6。

**事件概述**  
- 根据泄露信息，Gemini 3.5 Pro 的 UI 设计、SVG 生成等前端能力明显跃升，被指超越竞品 Fable 5。  
- 模型的主要短板集中于推理与编码领域，尤其在需要深度推理、大型仓库工程和长时间自主运行 Agent 的场景下表现不如 Fable 5 和 GPT-5.6。  
- 谷歌此次模型延期是由于更换了底层底座并重新进行预训练。基于同一底座，谷歌还计划推出对标 GPT-Image 2 的图像模型。

**方法/产品要点**  
- 前端与视觉代码生成能力是本次升级的核心亮点。  
- 模型尚未正式发布，当前信息均来自泄露版本，具体技术细节待官方确认。

**主要结果或产业意义**  
- 若泄露属实，Gemini 3.5 Pro 将在 UI 自动生成、设计稿转代码等场景中提供更强生产力，可能推动前端开发工具链的革新。  
- 同时揭示大型语言模型在“浅层”视觉生成任务与“深层”推理/工程任务之间的能力分化，厂商需在不同维度做差异化竞争。

**为什么重要**  
- 谷歌 Gemini 系列是 OpenAI GPT 系列的主要竞争对手，其模型迭代方向直接反映行业技术趋势。  
- 前端与视觉能力的突破可能改变网页/应用开发流程，降低设计门槛。  
- 延期并换底座预训练说明基础模型架构仍在快速演变，底层方法尚未收敛。

**局限与不确定性**  
- 所有能力均来自非官方泄露，正式版本可能有所不同。  
- 缺乏公开的基准测试数据，Fable 5 和 GPT-5.6 的具体性能对比无法独立验证。  
- 谷歌的图像模型计划同样仅为传闻，具体发布时间和规格待核实。

**可用于图书/PPT/简报的角度**  
- 以 Gemini 3.5 Pro 为案例，分析多模态与推理能力的“跷跷板效应”。  
- 结合谷歌换底座预训练的决策，讨论大模型研发中的底层技术路线选择。  
- 与 Fable 5、GPT-5.6 对比，展示当前 AI 竞争格局中“前端 vs 推理”的能力分化。
