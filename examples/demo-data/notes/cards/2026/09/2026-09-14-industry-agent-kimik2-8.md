# 知识卡片：Kimi K2.8 Preview 上线，百万上下文向所有会员开放

## 一句话结论
据腾讯研究院 AI 速递（20260914）转述，月之暗面于 9 月 11 日在 Kimi Code 与 Kimi Work 全量上线 Kimi K2.8 Preview，官方称其综合性能接近旗舰 K3，并把 1M 上下文从 K3 的高价位档下放给所有会员，成为公司在冲刺上市与 ARR 增长时接棒高成本旗舰的低成本主力。

## 事件概述或研究问题
- 来源材料称：月之暗面 9 月 11 日在 Kimi Code 与 Kimi Work 全量上线 K2.8 Preview。
- 官方口径：综合性能接近旗舰 K3，Coding 与 Agent 能力进一步提升。
- 商业侧同期信息：公司 8 月 ARR 突破 10 亿美元，年底目标 20 亿美元，并已向港交所递交上市申请；材料将其解读为“亟需低成本主力模型接棒高成本旗舰”。
- 年份未在摘录中明示（父级速递日期为 20260914，推测为 2026 年），待核实。

## 方法/产品要点
- 模型：Kimi K2.8 Preview（英文名保留，Preview 表明可能非最终正式版）。
- 上线入口：Kimi Code、Kimi Work（英文产品名保留）。
- 思考强度：支持 low、high、max 三档（thinking effort）。
- 输入模态：支持图片、视频输入。
- 上下文：1M context 向所有会员开放。
- 对照：旗舰 K3 的百万上下文仍需 199 元档以上会员。
- 能力侧重：Coding 与 Agent。

## 主要结果或产业意义
- 上下文窗口从“旗舰专属/高价位档”下放为“全员可用”，属于能力门槛而非单纯价格竞争的开放策略。
- 若“综合性能接近 K3”成立，则公司可在维持旗舰形象的同时，用更低成本模型承接编程与 Agent 类高频负载。
- 材料把模型发布与 ARR、上市申请放在同一段落，暗示资本市场叙事与产品迭代节奏相互绑定：高成本旗舰负责能力上限，低价主力模型负责规模与毛利。
- 与既有卡片的关系：本卡片聚焦模型供给侧的“可用性/定价/商业化”，而非 SIMA 2 的具身通用代理、Together 的推理性能基准或 Cursor Design Mode 的交互式前端编辑；增量信息是国产模型在 Agent/Coding 场景中的上下文开放与成本接棒逻辑。

## 为什么重要
- 对开发者：1M 上下文与多档思考强度若全员开放，长代码库、长文档与多步 Agent 任务的试错成本可能显著下降。
- 对行业：K2.8 Preview 与 K3 的档位差异，是观察“旗舰能力 → 主力模型 → 会员普惠”技术下沉路径的样本。
- 对商业化：在递交上市申请与 ARR 目标压力下，低成本主力模型能否既保体验又保毛利，比单次榜单成绩更关键。
- 对竞争格局：Coding 与 Agent 是当前 agent 赛道最直接的付费场景，上下文与思考强度是差异化卖点。

## 局限与不确定性
- 官方“综合性能接近 K3”的具体评测口径、基准与分数，材料未给出，待核实。
- K2.8 Preview 与正式版差异、后续是否替换 K3、是否影响 K3 定价，待核实。
- “所有会员”的具体会员层级、地区可用性、速率与配额限制，材料未说明，待核实。
- ARR 10 亿美元与年底 20 亿美元目标的统计口径、是否含未确认收入，待核实。
- 港交所上市申请的受理与进展状态，材料仅称“已递交”，待核实。
- 9 月 11 日的年份、以及该发布是否会受后续产品路线调整影响，待核实。

## 可用于图书/PPT/简报的角度
- “旗舰能力下放”曲线：从 K3 的 199 元档到 K2.8 全员 1M 上下文，展示模型能力的商品化节奏。
- Agent 时代的基础设施变量：上下文长度、思考强度档位、多模态输入如何共同决定 Agent 任务可行性。
- 上市前夜的产品叙事：ARR 目标、成本结构与模型迭代之间的关系。
- 中美前沿模型对照页：把“限速/安全”叙事与“低价普惠/规模”叙事并置，观察不同公司的优先级。
- 开发者成本清单：把 1M 上下文、三档思考强度、图片/视频输入作为选型对比维度。
