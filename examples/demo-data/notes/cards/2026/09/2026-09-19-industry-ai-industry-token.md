# 知识卡片：杨斌谈 Token 经济的“是”与“势”

## 一句话结论
杨斌在腾讯研究院新书《Token 经济》推荐序中提出，Token 是继蒲式耳、桶、千瓦时、比特之后的第五种关键计量单位，但又不只是计量单位；理解 Token 经济要同时看“是”（智力服务产出的本质逻辑）和“势”（AI 指数化放大后的产业走势），并始终回到“人”与“该做什么”。

## 事件概述或研究问题
- 材料为杨斌（清华大学经济管理学院教授、清华大学可持续社会价值研究院院长）为腾讯研究院新书《Token 经济》所写推荐序。书作者为白惠天、袁晓辉、司晓，腾讯研究院司晓出品；材料称出版时间 2026.8，实际出版状态待核实。
- 推荐序的问题意识：Token 对多数人有认知门槛，但政策制定者和产业先锋不能忽视或低估；碎片化内容易生误读，因此需要一本系统讲清 Token 及其经济学原理的书。
- 主线：从“Token 是什么”讲到 Token 经济的产、供、销逻辑，以及跨境服务、制度规则和人的价值选择。

## 方法/产品要点
- 该书用计量单位类比开篇：蒲式耳之于农业、桶之于石油、千瓦时之于电力、比特之于信息；第五种是 Token 之于 AI。
- 作者立论：Token 是“人类历史上第一个用来计量类似人类智力活动产出的基本单位”；但杨斌强调，Token “计量的是智力服务的产出，但它本身并不是智力”。
- Token 是“两头都量”的单位：供给端是成本，需求端是用量和价值；造 Token 需要“五层蛋糕”合力，材料称硬件约占七成，具体口径待核实。
- 杨斌提出/发挥“AI 次方”框架：不是“AI+”（better、有限游戏、绩效优化），而是把 AI 放到指数位，倒逼底数“x”质变；在 Token 经济中，底数是“智力服务”，AI 在指数位放大它，Token 计量放大的起、程、果。
- 三条与互联网逻辑的不同：边际上从“越用越便宜”翻为“越用仍越烧”；需求上从“人撑出来的”翻为“自己长出来的”；胜负手上从“均价与规模”翻为“陡峭与稀缺”。
- 制度层面，推荐序特别提到第七章：Token 出海触及算力与能源出口，“包裹 Token 的服务贸易”最接近成熟贸易形态，WTO、GATS 旧分类已装不下。

## 主要结果或产业意义
- Token 经济的核心矛盾：Token 消耗量暴涨，可能是生意做大，也可能是成本失控；同一数字有两种解读，需分辨。
- “消耗即生产”：烧掉的 Token 可能沉淀为可复用工作流和企业资产；智能体跑任务消耗 Token，又喂出下一步判断。
- 差异化下沉：当模型层趋同、开源钉死价格天花板，AI 作为指数日趋公共品化，真正拉开差距的是底数——用 Token 做的那件事值不值。
- 复利判据：用一次能让下一次更便宜、更精准的智力服务（可缓存、可复用、能沉淀），底数大于 1；用完即弃则底数小于 1。企业“AI 次方”的关键，是把智力服务做成复利资产而非消耗品。
- 互联网大厂风险：免费获客、规模即护城河、抢用户时长、补贴换份额、小步快跑等“肌肉记忆”，照搬进 AI 时代可能适得其反；需要“扬弃”（德语 aufheben），既克服又保留。
- 当前仍是学习阶段：2025—2026 年经历“Token 随便用”到“大厂算不过来账、要限制”的一放一收；书中的判断是 2025—2026 切片快照，作者也强调“只是当前格局”。
- 人的位置：Token 经济的终点依然是人；计量 Token 多寡只是入门，思量什么该做、什么不该做才是真人。材料提到 CTMR（批判性思维与道德推理）、“心件”、“吾辈如神，自当善任”。

## 为什么重要
- 对政策制定者：Token 若不进入政策文件和指标体系，可能被低估；Token 出海、算力与能源出口、服务贸易规则真空，都需要新认知。
- 对企业经营者：AI 时代不是简单把互联网打法加一个 AI 插件；底数、复利、消耗与价值的关系会重新定义投入产出。
- 对个人与教育：推荐序鼓励年轻人“把 Token 用足”，把学校发放的 Token 额度类比为过去的“机时卡”“上机票”，视为成才培养经费与“奥德赛岁月”的探索资本。
- 与已有卡片的关系：本条不直接延续 NVIDIA/Palantir、NIST AI RMF 或 Epoch AI 卡片；增量在于提供 Token 经济的中文概念框架、产业治理视角和“AI 次方”论述。

- “Token 是第一个用来计量类似人类智力活动产出的基本单位”是书中的大胆立论，属观点性判断，学界与产业界是否有共识待核实。

## 可用于图书/PPT/简报的角度
- “第五种计量单位”：蒲式耳—桶—千瓦时—比特—Token 的文明演进线。
- 从比特到 Token：从“数据处理”到“智能涌现”。
- Token 的两副面孔：供给端成本 vs 需求端用量与价值；“消耗即生产”。
- AI+ vs AI 次方：better / differ，有限游戏 / 无限游戏，绩效优化 / 重构新物种。
- 底数、指数、尺子：智力服务为底数，AI 为指数，Token 为尺子。
- 复利资产 vs 消耗品：判断 AI 投入是否形成复利的简洁框架。
- 互联网逻辑失效点：越用越烧、需求自生长、均价失灵与稀缺。
- 规则真空与 Token 出海：算力能源出口、包裹 Token 的服务贸易、WTO/GATS 旧分类。
- 终点是人：CTMR、“心件”、该做与不该做的分寸。
- 年轻人与组织学习：把 Token 用足、自由探索、允许“乱花”中的长期底稿。
