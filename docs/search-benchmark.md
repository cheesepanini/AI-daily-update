环境：WSL，项目 `.venv-linux`，临时目录中的 2,000 张合成 Markdown 卡片；每张含中英文正文，均为已审核卡片。使用 `data/benchmark_search.py`；计时不含卡片生成。旧路径为 `public_cards` + `filter_public_cards`，新路径为 `search_public_cards`，两者均返回未分页的匹配列表。单位：毫秒，单次测量，结果用于观察量级而非稳定吞吐承诺。

首次查询会按文件时间和大小填充 SQLite 缓存，因此可能慢于旧路径。后续查询仍需扫描文件目录和读取文件元信息以发现直接修改，但仅解析变化的卡片。SQLite 对包含式关键词使用 `LIKE`，前置通配符不能使用普通 B-tree 词项索引；当前目标是数千张卡片，若规模显著增长需重新测量。真实本地工作区当前只有少量卡片，本表不代表云端实测。
